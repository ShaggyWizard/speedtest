# speedtest

Консольный скрипт на Node.js. Делает 10 запросов к указанному адресу по очереди, каждый раз дожидается полного ответа и печатает скорость скачивания.

## Запуск

Нужен Node.js 18 или новее. Зависимостей нет, `npm install` не нужен.

```bash
node speedtest.js <адрес> [количество запросов]
```

Пример с файлом на 10 МБ:

```bash
node speedtest.js "https://speed.cloudflare.com/__down?bytes=10000000"
```

Второй аргумент необязательный, по умолчанию 10 запросов.

## Что печатает

```
Адрес: https://speed.cloudflare.com/__down?bytes=10000000
Запросов: 10, по одному

   1. 812 мс, 10.00 МБ
   ...
  10. 790 мс, 10.00 МБ

Среднее время запроса: 801 мс
Всего скачано: 100.00 МБ (100000000 байт)
Скорость скачивания: 99.87 Мбит/с (12.48 МБ/с)
```

## Единицы измерения

- Скорость — **Мбит/с** (мегабиты в секунду), в скобках та же скорость в МБ/с. 1 Мбит = 1 000 000 бит, 1 МБ = 1 000 000 байт.
- Время запроса — миллисекунды, от отправки до последнего байта ответа.
- Объём — мегабайты и точное число байт.

## Как считается

- Скорость = все скачанные байты × 8 / суммарное время всех запросов.
- Объём считается по телу ответа после распаковки. Если сервер сжимает ответ (gzip), по сети прошло меньше байт. Для замера бери уже сжатый файл: картинку, видео, архив.
- В суммарное время входит установка соединения. На маленьком файле она занимает заметную долю, и скорость выйдет заниженной. Бери файл от 5 МБ.

## Ошибки

Скрипт останавливается с кодом 1 и пишет причину, если адрес неверный, сервер ответил не 2xx, запрос не уложился в 60 секунд или ответ пустой.
